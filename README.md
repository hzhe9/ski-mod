# Modern Skis

A Fabric mod that adds alpine skis, a snowboard and a ski pole to Minecraft.

## Contents

| Item | ID | Description |
|---|---|---|
| Alpine Skis | `skis:modern_ski` | Foot equipment; a pair of parallel boards worn in the boots slot. The full board model is also shown while the item is held in hand |
| Snowboard | `skis:snowboard` | Foot equipment; a single wide board worn in the boots slot, ridden with both feet side by side |
| Ski Pole | `skis:ski_pole` | Held in hand; right-click to plant it and push forward |

## Behaviour

- **Gliding**: standing on snow or ice while wearing a board starts a low-friction glide; slopes accelerate you along your current horizontal velocity, not along where the body faces.
- **Momentum and braking**: speed carries between slopes. On alpine skis, holding back while moving forward brakes without steering.
- **Steering**: the snowboard carves with the upper body locked to the board; A/D slide along the board's axis.
- **Pole push**: a right-click plants the pole, plays one arm swing and gives a push that decays over a second.
- **Contact behaviour**: skis and snowboard suppress the vanilla walking footstep sounds and camera bob while gliding, add snow spray from the board edges and a carving sound that gets denser with speed, and remove fall damage on snow.

## Styles

Each board comes in six cosmetic styles with identical stats. The style only changes the item model and the display name, both stored in the crafted item's components, so nothing about handling differs.

`wood` (base) · `graphite` · `topo` · `brushed` · `neon` · `leopard`

## Requirements

- Minecraft **26.2**
- Fabric Loader **≥ 0.19.5**
- Fabric API
- Java **≥ 25**

## Installation

1. Install Fabric Loader and Fabric API
2. Put the jar into `.minecraft/mods/`
3. Launch the game

## Building

```bash
./gradlew build
# Output: build/libs/skis-mod-<version>.jar
```

## Texture generation

All textures, item models and icons are generated by scripts, with no external assets required:

```bash
python tools/gen_assets.py
```
