# Skis — Minecraft 26.2 滑雪模组

在雪坡上真正滑起来的三件装备：**高山滑雪板（双板）**、**滑雪单板**、**滑雪杖**。
低摩擦滑行 · 下坡加速 · 动量与压刃刹车 · 撑杖冲刺 · 单板人板一体的 carve 转弯 · 滑行时从板两侧扬起的雪粒子（越快越大、急减速炸一团） · 摔在雪面上不受伤，两种板各 6 款外观。

## 物品

| id | 名称 | 槽位 | 说明 |
|---|---|---|---|
| `skis:modern_ski` | 高山滑雪板（双板 / Alpine Skis） | 脚部（靴子） | 两块平行的板（长 24 单位 = 150 cm），两腿各向外平移 0.9 单位；**拿在手上 = 完整板模型**（竖持、无雪鞋，`display_context` 分流） |
| `skis:snowboard` | 滑雪单板（Snowboard） | 脚部（靴子） | 一只板（宽 5.76 = 36 cm、长 22 单位 + 两头各 2 单位翘头 = **twin-tip**，含翘总长 26 单位 = 162.5 cm），两脚**平行并列**站在板上；穿上后完全站定、身体不跟视角转，只有 A/D 能沿身体左右平移（见 `docs/tuning.md`「单板」）；**拿在手上 = 完整板模型**（竖持、无雪鞋） |
| `skis:ski_pole` | 滑雪杖 | 手 | 右键撑杖 → 一次摆臂 + 一段逐渐衰减的冲刺；手上与物品栏都是**真 3D 模型**（物品栏走缩进一格的 GUI 版，不再是平面图标） |

### 6 种外观款式（纯装饰）

两种板各有 6 款，**数值完全相同**，款式只写在成品的两个原版组件里：

- `minecraft:item_model` → 换物品图标 + 脚上模型贴图：图标是**真 3D 模型**（`assets/skis/models/item/<id>_<款>.json`，方块模型 `elements` 格式，**直接复用脚上那张 128x32 贴图**，不另画图）；角度由模型自己的 `display.gui.rotation` 决定
- `minecraft:custom_name` → 翻译键 `item.skis.<id>.<款>`（中英各一份 lang，可本地化）

| # | 款式 | 中文名 | 英文名 | 双板配方（无序） | 单板配方（无序） |
|---|---|---|---|---|---|
| 1 | wood | 高山滑雪板 · 木纹 | Wood Grain Alpine Skis | **基础款**：皮革×2 + 木板×4（`L L` / `P P` / `P P`） | **基础款**：皮革×2 + 木板×3（`L L` / `PPP`） |
| 2 | graphite | · 石墨 | Graphite | 木纹板×1 + 煤炭×1 + 铁锭×1 | 同左（用木纹单板） |
| 3 | topo | · 等高线 | Topo | 木纹板×1 + 纸×1 + 铁锭×1 | 同左 |
| 4 | brushed | · 拉丝 | Brushed | 木纹板×1 + 铁锭×1 + 青金石×1 | 同左 |
| 5 | neon | · 霓虹 | Neon | 木纹板×1 + 洋红/橙/黄绿染料各×1 | 同左 |
| 6 | leopard | · 豹纹 | Leopard | 木纹板×1 + 皮革×1 + 墨囊×1 | 同左 |

基础款是有序合成（两种板原料相同，靠**图案**区分）；5 个衍生款是无序合成，消耗一块木纹板 + 材料。
因为任何款式的板都算 `skis:modern_ski` / `skis:snowboard`，**已做好的其他款式也能再改款**（换款式不亏材料）。
滑雪杖：铁粒×1 + 木棍×2（`I` / `S` / `S`，一次出 2 根）。
## 安装

1. 环境：**Minecraft 26.2** + **Fabric Loader ≥ 0.19.5** + **Fabric API** + **Java 25**
2. 把 `skis-mod-<版本>.jar` 丢进实例的 `mods/` 目录
3. 启动即可。mod 声明 `environment: *`：滑行与冲刺的力在**服务端** tick 上结算，所以联机时服务器也要装；单人游戏装客户端就够。

## 兼容性与已知限制

- 只支持 26.2 的 Fabric；没有 Forge / NeoForge 版本。
- 穿板会临时改玩家的**台阶高度**（`STEP_HEIGHT` 0.6 → 1.0）与移动属性，脱板恢复。
- 穿板时**脚步音效与落地闷响会被静音**、走路镜头晃动被取消。这会连带压掉第三方脚步音效模组（如 PresenceFootsteps）的效果 —— 这是有意为之（滑行不该有脚步声）。
- 穿板**摔落在雪 / 冰面上不掉血**（只免摔落伤害，别的伤害照常；砸在石头 / 泥土上照旧摔伤）。
- 滑行时的雪粒子是**纯客户端观感**：粒子多少不影响速度，也不影响联机时的判定。
