# Modern Skis

A Fabric mod that adds a pair of skis and a ski pole to Minecraft. 1.0.0 is the first public release.

## Contents

| Item | ID | Description |
|---|---|---|
| Modern Skis | `skis:modern_ski` | Foot equipment; once worn, the leg stance is rendered in sync with the ski board model attached to the feet |
| Ski Pole | `skis:ski_pole` | Push off with the pole to accelerate |

- **Starting off**: right-click to kick off into a glide, and push with the pole to accelerate
- **Stance**: the legs spread outwards while gliding, and the two boards spread with them while staying parallel
- **Sound and visuals**: step sounds, landing sounds and camera bob are handled separately for the gliding state, so the walking animation and the vanilla walk bob no longer play while gliding

## Requirements

- Minecraft **26.2**
- Fabric Loader **≥ 0.19.5**
- Fabric API
- Java **≥ 25**

## Installation

1. Install Fabric Loader and Fabric API
2. Put the built jar into `.minecraft/mods/`
3. Launch the game

## Building

```bash
./gradlew build
# Output: build/libs/skis-1.0.0.jar
```

## Texture generation

All textures and model UVs are generated by a script, with no external assets required:

```bash
python tools/gen_assets.py
```
