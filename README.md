# Skis — Minecraft 26.2 滑雪模组

在雪坡上真正滑起来的三件装备：**高山滑雪板（双板）**、**滑雪单板**、**滑雪杖**。
低摩擦滑行 · 下坡加速（沿当前水平速度，不跟随身体朝向） · **贴地重力加重（双板 ×1.5 / 单板 ×1.3）、腾空改原版 0.9 倍（0.072，飘一点、滞空更长）** · 动量滑行（双板按住 S 在前滑时＝刹车，不拨方向） · 撑杖冲刺 · 单板人板一体的 carve 转弯 · 滑行时从板两侧扬起的雪粒子（越快越大、急减速炸一团）与随速度变密的切雪声 · 摔在雪面上不受伤、也不响落地声，两种板各 6 款外观。

## 物品

| id | 名称 | 槽位 | 说明 |
|---|---|---|---|
| `skis:modern_ski` | 高山滑雪板（双板 / Alpine Skis） | 脚部（靴子） | 两块平行的板（长 24 单位 = 150 cm），两腿各向外平移 0.9 单位；**拿在手上 = 完整板模型**（竖持、无雪鞋，`display_context` 分流） |
| `skis:snowboard` | 滑雪单板（Snowboard） | 脚部（靴子） | 一只板（宽 5.76 = 36 cm、长 22 单位 + 两头各 2 单位翘头 = **twin-tip**，含翘总长 26 单位 = 162.5 cm），两脚**平行并列**站在板上；穿上后完全站定、身体不跟视角转，只有 A/D 能沿身体左右平移（见 `docs/tuning.md`「单板」）；**拿在手上 = 完整板模型**（竖持、无雪鞋） |
| `skis:ski_pole` | 滑雪杖 | 手 | 右键撑杖 → 一次摆臂 + 一段逐渐衰减的冲刺；手上与物品栏都是**真 3D 模型**（物品栏走缩进一格的 GUI 版，不再是平面图标） |

### 6 种外观款式（纯装饰）

两种板各有 6 款，**数值完全相同**，款式只写在成品的两个原版组件里：

- `minecraft:item_model` → 换物品图标 + 脚上模型贴图：图标是**真 3D 模型**（`assets/skis/models/item/<id>_<款>.json`，方块模型 `elements` 格式，**直接复用脚上那张 128x32 贴图**，不另画图）；角度由模型自己的 `display.gui.rotation` 决定
- `minecraft:custom_name` → 翻译键 `item.skis.<id>.<款>`（中英各一份 lang，可本地化）

| # | 款式 | 中文名 | 英文名 | 双板配方（无序） | 单板配方（无序） |
|---|---|---|---|---|---|
| 1 | wood | 高山滑雪板 · 木纹 | Wood Grain Alpine Skis | **基础款**：皮革×2 + 木板×4（`L L` / `P P` / `P P`） | **基础款**：皮革×2 + 木板×3（`L L` / `PPP`） |
| 2 | graphite | · 石墨 | Graphite | 木纹板×1 + 煤炭×1 + 铁锭×1 | 同左（用木纹单板） |
| 3 | topo | · 等高线 | Topo | 木纹板×1 + 纸×1 + 铁锭×1 | 同左 |
| 4 | brushed | · 拉丝 | Brushed | 木纹板×1 + 铁锭×1 + 青金石×1 | 同左 |
| 5 | neon | · 霓虹 | Neon | 木纹板×1 + 洋红/橙/黄绿染料各×1 | 同左 |
| 6 | leopard | · 豹纹 | Leopard | 木纹板×1 + 皮革×1 + 墨囊×1 | 同左 |

基础款是有序合成（两种板原料相同，靠**图案**区分）；5 个衍生款是无序合成，消耗一块木纹板 + 材料。
因为任何款式的板都算 `skis:modern_ski` / `skis:snowboard`，**已做好的其他款式也能再改款**（换款式不亏材料）。
滑雪杖：铁粒×1 + 木棍×2（`I` / `S` / `S`，一次出 2 根）。

## 操作（穿着板时）

| 键 | 双板 | 单板 |
|---|---|---|
| W / S | W 前进；按住 S 且还在往前滑＝刹车，停下 / 倒滑时才往后走 | W 前倾 / S 后倾（只改滑行方向，不给推力） |
| A / D | 转身体（视角不跟着转） | 沿身体左右平移 |
| 鼠标 | 转视角，限在身体左右各 90° | 转视角，限在身体左右各 135° |
| 空格 | 空格先起跳 —— **起跳由本模组接管**（不走原版 `aiStep` 的 `jumping &&（onGround 或 水中）` 分支）：贴地立即跳，离地 6 tick 逗留窗内也能跳（**只有这两条**）；按下后有 5 tick 输入缓冲（提前按也算）；10 tick 冷却在起跳后**与「这一趟腾空里起过跳 / 开过翻」的落地时**都重新起算 —— 跳过 / 翻过之后落地 0.5 s 内不能起跳，按住也不行（只是从坡上滑落、走下台阶落地的**不罚**）。速度越快跳越高 —— **按住多久就转多少**：前 4 tick 不动（静止段），第 5 tick 起每 tick 16°（两板都是 1.125 s 一圈）；**松手定格，空中已开翻过则下一 tick 立刻续翻**（只有从地面起跳那一下要重新数满 4 tick），落地角度不对会摔 | 同左 |
| 右键 | 拿滑雪杖时撑杖冲刺 | — |

## 安装

1. 环境：**Minecraft 26.2** + **Fabric Loader ≥ 0.19.5** + **Fabric API** + **Java 25**
2. 把 `skis-mod-<版本>.jar` 丢进实例的 `mods/` 目录
3. 启动即可。mod 声明 `environment: *`：滑行与冲刺的力在**服务端** tick 上结算，所以联机时服务器也要装；单人游戏装客户端就够。

## 兼容性与已知限制

- 只支持 26.2 的 Fabric；没有 Forge / NeoForge 版本。
- 穿板会临时改玩家的**台阶高度**（`STEP_HEIGHT` 0.6 → 1.0）、**重力**（`GRAVITY`：贴地双板 ×1.5 = 0.12、单板 ×1.3 = 0.104；腾空两板 ×0.9 = 0.072 格/tick²）与移动属性，脱板恢复。
- 重力是**真重力**（`Attributes.GRAVITY` 属性），但**分成贴地 / 腾空两档**：贴地 ×1.5（双板）/ ×1.3（单板）下落干脆、不发飘；**一跳起来就换成 ×0.9（＝原版 0.072，比平时轻一点）**，所以空中飘一点、滞空更长（空翻能按住的 tick 更多）。两档都由 `GRAVITY_MULTIPLIER` / `AIR_GRAVITY_MULTIPLIER` 控制，跳高表按空中的 0.072 反解（起跳首 tick 仍是贴地档），满速 1.50 格。
- 穿板时**脚步音效与落地闷响会被静音**、走路镜头晃动被取消。这会连带压掉第三方脚步音效模组（如 PresenceFootsteps）的效果 —— 这是有意为之（滑行不该有脚步声）；滑行时改用模组自己的**切雪声**（间隔与音量随速度，见 `docs/tuning.md`「滑行音效」）。
- 穿板**落地前 3 秒内踩过雪地、或落点就是雪 / 冰面，就不掉血、也不响落地声**（只拦摔落这一种；别的伤害照常，在石头 / 泥土上站够 3 秒再摔照旧摔伤 + 闷响）。
- 滑行时的雪粒子与切雪声都是**纯客户端**的：不影响速度，也不影响联机判定；按 Esc 暂停时会跟着停。
- 穿板时**视角相对锁定的身体朝向限在左右各 90°（双板，合计 180°）/ 135°（单板）**：没顶到限位时视角只管鼠标、身体在下面转；顶到之后头被身体平滑拖着走，往回转立刻响应（不留死区）。
- 双板**按 W 时身体会朝视角方向转**（2.4°/tick，转的是身体、视角本身不动）：鼠标看向哪边，按住 W 就顺着那边拐过去，不用先松手按 A / D。
- 穿板时**不能骑乘**（矿车 / 船 / 生物 / 坐垫类 mod / `/ride`）、**不能开鞘翅**、**不能爬梯子 / 藤蔓 / 脚手架**、**不能游泳**（落水没有游泳姿态与游泳推进，按住空格仍能上浮）—— 这四个都是**服务端**拦截，联机同样生效；已经在车上再穿上板会**被自动请下车**，飞着 / 游着再穿上板当 tick 就打断。单板双板一致。
- 装了 **Vivid Move（灵动）**时二者自动兼容：**穿着板时 Vivid Move 的全身玩家动画停用**，身体保持本模组的滑行站姿；它的相机、眼睛、拖尾、血迹、打击反馈照常。这套兼容是可选 mixin 配置，只在检测到 `vivid_move` 时生效，没装就等于不存在。
- **创造模式飞行时不触发滑雪逻辑**：`Abilities#flying` 为真的每一 tick，穿板也不改写移动输入、不写速度、不转身体、不起跳 / 不空翻、撑杖不给冲刺，也没有雪粒子与切雪声 —— 飞行完全按原版走（WASD / 抬头低头都不受影响）。落地或退出飞行后**下一 tick 自动恢复**，不需要重新穿板。单板双板一致。
