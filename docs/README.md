# 文档目录

面向使用者的说明在仓库根的 [`README.md`](../README.md)；这里是工程文档。

| 文档 | 什么时候读它 |
|---|---|
| [`tuning.md`](tuning.md) | 要改手感 / 查某个数值的现值 / 问"两块板有什么区别" —— **工程数值的唯一事实源** |
| [`assets.md`](assets.md) | 动贴图、模型几何、物品图标、加外观款式 |
| [`dev-setup.md`](dev-setup.md) | 拉代码构建、装机、看架构与源集划分、踩过的坑 |

约定两条：

1. **数值只写在 `tuning.md`**，其它文档不复制数值（复制过的都过期了）。
2. **枚举类清单不手写**：分支差异、文件清单这类用 `git` 现取（`git diff --name-only main swing`）。
